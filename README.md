# Overview

As a software engineering student and IT support specialist, I am continuously expanding my technical skills by exploring modern programming languages, system automation, and development workflows. Building foundational programs helps me establish clean coding practices and master the tooling required for robust software engineering.

This software is a modern, personalized implementation of the classic "Hello World" program. Beyond printing a standard greeting, it features custom console formatting, user input handling, and a structured output designed to demonstrate basic command-line interaction.

The purpose of this project is to set up a fully functional development environment—integrating Git, GitHub, and VS Code—while practicing the end-to-end workflow of writing, testing, version-controlling, and publishing software documentation.

[Software Demo Video](https://youtu.be/MD6q-WvFb30)

# Development Environment

* **IDE / Editor:** Visual Studio Code (VS Code) for code editing, terminal management, and project organization.
* **Version Control:** Git and GitHub for tracking code changes, repository management, and publishing public deliverables.
* **Operating System:** Linux / Arch Linux development environment configured with custom shell tools and CLI utilities.
* **Programming Language:** Rust.
